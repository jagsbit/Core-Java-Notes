# Java Streams — Beginner Practice Questions

---

## Q1. Average of a List
Given a list of integers, find the **average** of all elements.

**Sample Input:**
```
[1, 2, 3, 4, 5, 6, 7]
```
**Sample Output:**
```
4.0
```
