---

## 1. Anagrams

**Question:**
Given a list of words and a target word, find all words in the list that are anagrams of the target word.

**Sample Input:**
```
words  = ["listen", "silent", "enlist", "google", "inlets"]
target = "silent"
```

**Sample Output:**
```
[listen, silent, enlist, inlets]
```
