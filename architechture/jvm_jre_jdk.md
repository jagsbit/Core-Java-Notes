# Difference Between JVM, JRE, and JDK in Java

When you're learning Java, terms like **JVM**, **JRE**, and **JDK** come up all the time. Understanding how they differ and how they connect is fundamental to working with Java.

---

## The 3 Core Components of Java

Java is designed to be **platform independent**, and that's possible because of its architecture. These three are the building blocks:

| Component | Full Form | Role |
|-----------|-----------|------|
| **JVM** | Java Virtual Machine | Runs the bytecode |
| **JRE** | Java Runtime Environment | Provides runtime environment |
| **JDK** | Java Development Kit | Full toolkit for developers |

### Visual Diagram

```
┌──────────────────────────────────────────┐
│               JDK                        │
│  ┌────────────────────────────────────┐  │
│  │              JRE                   │  │
│  │  ┌──────────────────────────────┐  │  │
│  │  │           JVM                │  │  │
│  │  │  (Bytecode → Machine Code)   │  │  │
│  │  └──────────────────────────────┘  │  │
│  │  + Core Libraries (java.util, etc) │  │
│  └────────────────────────────────────┘  │
│  + javac, debugger, JAR tool, javadoc    │
└──────────────────────────────────────────┘
```

> **JDK ⊃ JRE ⊃ JVM**

---

## 1. JVM — Java Virtual Machine

**JVM** is the engine that runs your Java program.

### Key Points

- JVM is an **abstract machine** — it doesn't exist physically.
- It reads the **bytecode** (`.class` files) generated by the Java compiler.
- Converts bytecode into **machine code** for the underlying OS (Windows, macOS, Linux).
- JVM itself is **platform dependent**, but the bytecode it runs is **platform independent**.

### How It Works

```
Java Source Code (.java)
        ↓
   Java Compiler (javac)
        ↓
    Bytecode (.class)
        ↓
       JVM
        ↓
  Machine Code (OS specific)
```

### JIT Compiler (Just-In-Time)

> JVM includes a **JIT Compiler** which improves performance by compiling frequently used bytecode into native machine code **during execution**.

---

## 2. JRE — Java Runtime Environment

### Definition

$$\text{JRE} = \text{JVM} + \text{Core Class Libraries}$$

### Key Points

- Includes the **JVM**.
- Includes core libraries like `java.util`, `java.io`, `java.lang`, etc.
- If you just want to **run** a Java program (not write or compile it), **JRE is enough**.
- End users who only run Java applications need the JRE.

### What JRE Contains

| Component | Description |
|-----------|-------------|
| JVM | Executes bytecode |
| `java.util` | Utility classes (ArrayList, HashMap, etc.) |
| `java.io` | Input/Output classes |
| `java.lang` | Core classes (String, Math, Object, etc.) |
| `java.net` | Networking classes |

---

## 3. JDK — Java Development Kit

### Definition

$$\text{JDK} = \text{JRE} + \text{Development Tools}$$

### Key Points

- If you're a **Java developer**, you need JDK to **write, compile, and run** programs.
- It is the **complete package** for Java development.

### What JDK Contains

| Tool | Description |
|------|-------------|
| `javac` | Java Compiler — compiles `.java` to `.class` |
| `java` | Java Launcher — runs the program |
| `javadoc` | Documentation Generator |
| `jar` | JAR tool — packages classes into `.jar` files |
| `jdb` | Java Debugger |
| JRE | Full runtime environment included |

---

## 4. Key Differences

| Feature | JVM | JRE | JDK |
|---------|-----|-----|-----|
| **Full Form** | Java Virtual Machine | Java Runtime Environment | Java Development Kit |
| **Purpose** | Runs bytecode | Runs Java programs | Develops & runs Java programs |
| **Contains** | Bytecode interpreter + JIT | JVM + Libraries | JRE + Dev tools |
| **Platform Dependent?** | Yes | Yes | Yes |
| **Who Uses It?** | Internally by JRE | End users | Developers |
| **Can Compile Java?** | ❌ No | ❌ No | ✅ Yes |
| **Can Run Java?** | ✅ Yes | ✅ Yes | ✅ Yes |

---

## 5. Bonus Terms

### JSE — Java Standard Edition

- **Core Java** used in desktop and server applications.
- Includes all standard libraries and APIs.

### JEE — Java Enterprise Edition

- **Advanced Java** for enterprise-level applications.
- Includes: Servlets, JSP, EJB, JPA, etc.

### JME — Java Micro Edition

- Designed for **mobile and embedded systems**.
- Lightweight version of Java.

| Edition | Full Form | Used For |
|---------|-----------|----------|
| **JSE** | Java Standard Edition | Desktop / Server apps |
| **JEE** | Java Enterprise Edition | Web / Enterprise apps |
| **JME** | Java Micro Edition | Mobile / Embedded devices |

---

## 6. Quick Summary

```
┌────────────────────────────────────────┐
│  JDK  →  For Developers                │
│  JRE  →  For Running Applications      │
│  JVM  →  The Engine Inside Both        │
└────────────────────────────────────────┘
```

> - **JDK** is for developers — write, compile, and run Java.
> - **JRE** is for end users — only run Java applications.
> - **JVM** is the core engine that executes bytecode on any platform.
